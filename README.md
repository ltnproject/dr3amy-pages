# Dr3amy Pages 🌙

**Static, small, yours.**

[![License](https://img.shields.io/badge/license-Dr3amy%20Pages%20Attribution-blue.svg)](LICENSE)

Simple static page publishing, backed by GitHub.

Create a page, edit the HTML, and publish it to:

**`dr3amy.creepers.pro/p/your-page/`**

Your pages are stored in your own `dr3amy-pages` GitHub repository.

No server. No deploy step. Just a link.

## Features

- Templates to get started
- Browser-based HTML editor
- GitHub-backed storage
- Fast publishing
- Simple page management
- Custom domains coming soon

## Repository

    dr3amy-pages/
    └── p/
        └── your-page/
            └── index.html
